# MeasureTape

Tape measure reading → millimeters, instantly. Mobile-first PWA, installable to your iOS home screen.

Type (or tap) something like `24 1/8` and get `612.78mm` back immediately. Built for a job that's mostly mm measurements but a tape measure that only speaks fractions of an inch.

## Stack

Next.js 16, React 19, Tailwind v4.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Install on iOS

Open in Safari → Share → Add to Home Screen. Runs full-screen, no browser chrome.
